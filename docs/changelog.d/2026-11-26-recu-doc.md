## [2026-11-26] — Méthode : reçu doc, une modification de documentation seule ne lance que le contrôle de méthode et de secrets
**Quoi :** `node scripts/verify-receipt.mjs docs-only` (exit 0 si tout ce qui diffère de HEAD, hors chemins exclus du reçu, est un `.md` sous `.method/`, `docs/`, `.claude/skills/`, `.claude/agents/`, ou `CLAUDE.md` / `README.md` à la racine : liste `DOC` de `scripts/lib/arbre-de-code.mjs`). `pnpm verify:cached` (`node scripts/verify-receipt.mjs cached`) : reçu valide → rien ; doc seule → `check:framework` puis `node scripts/check-public.mjs --secrets-only`, puis un reçu `scope: "docs"` (`check:framework`, `check:public`), un échec rendant la main sans repli sur `pnpm verify` ; sinon `pnpm verify`. Le reçu doc se juge sur son arbre de code, pas sur HEAD : le gate et `.githooks/pre-commit` (`check --commit`) ne l'acceptent que si ce qui diffère de HEAD est encore de la doc seule, ou rien (le rebase ou le merge qui suit le commit de doc). Les checks déclarés par un reçu (les 4, ou `check:framework` et `check:public` pour un reçu doc) sont contrôlés par `checkReceipt` et non plus par le seul gate : un autre dépôt jugé par son propre script refuse aussi un reçu incomplet. La mutualisation de `scripts/long-run.mjs` ne compte plus un reçu doc comme couvrant un `verify`. `pnpm commit:export` accepte un reçu doc (`pnpm check:framework && node scripts/check-public.mjs --secrets-only && node scripts/verify-receipt.mjs write check:framework,check:public docs` dans l'export) quand le commit ne change que de la doc par rapport à son premier parent, et l'écrit avec `Verified: docs seule, check:framework, check:public, <date>` ; le job `recu` de la CI (`scripts/ci/recu.mjs`) signale un tel trailer sur un commit qui change autre chose (`docHorsDoc`).
**Pourquoi :** décision de JB : une modification de documentation seule ne demande que le contrôle de méthode et de secrets ; rejouer type-check, lint et les tests sur un code inchangé ne prouvait rien et coûtait une vérification complète à chaque modification de méthode, alors qu'un document peut encore porter un secret recopié.
