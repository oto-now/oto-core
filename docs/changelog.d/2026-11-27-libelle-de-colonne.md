## [2026-11-27] — Tableaux : un libellé déclaré pour chaque colonne (#225)
**Quoi :** une colonne de tableau peut déclarer un `label` facultatif (1 à 100 caractères, blancs de bord retirés), dans `tableColumnSchema` et le patch d'en-tête de `write` (`tableColumnPatchSchema`), fusionné comme les autres attributs et gardé par un changement de type ; la publication nomme son changement (« changed ref (label) ») ; `table.schema` le sert dans `columns` et dans la ligne de la colonne (« shown as « Montant estimé » »), et la règle 1 du contrat `write.table` le cite. L'écran l'affiche partout où il montre une colonne (en-tête de la grille, filtre, provenance, totaux et compte par état, file de revue, vue d'une page) par `libelleDeColonne` et `libelleDuNom` (`ui/tableau/libelles.ts`) ; sans libellé, le nom, comme avant.
**Pourquoi :** issue #225 : le nom interne (`montant_estime`) n'a ni accents ni sigles.
**Problèmes :** aucune unicité exigée ; un libellé se remplace mais ne s'efface pas (comme `max_length`). Le libellé tiré du nom reste le nom brut : la casse de phrase des en-têtes est l'affaire de #224. Ajout seul au contrat MCP (ADR-002). Aucune migration.
