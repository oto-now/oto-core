## [2026-11-26] — Méthode : synchro du template (80c2c2d), conventions et système de design hors de l'arbre de code
**Quoi :** `.method/conventions/` (registry compris) et `docs/design/` rejoignent les exclusions de l'arbre de code (`scripts/lib/arbre-de-code.mjs`, `EXCLUS`) : un changement qui ne touche qu'eux n'invalide plus le reçu, et un commit de ces seuls documents garde l'arbre de code de son parent. Du template : `long-run` n'accepte plus pour un `verify` mutualisé qu'un reçu complet (jamais un reçu doc), `.githooks/pre-commit` et le gate passent `check --commit` au script de reçu d'un autre dépôt de la méthode (un dérivé n'y accepte son reçu doc que pour un commit de doc seule) ; messages entre sessions limités aux sessions de ce dépôt (`CLAUDE.md § Plusieurs sessions`, point 0). L'exception « état vide de première utilisation » de `ui-patterns.md` était déjà là. Le reçu doc du template (`docs-only`, `write check:framework docs`) n'est pas porté : ici, ce rôle est tenu par les exclusions de l'arbre de code.
**Pourquoi :** synchro du template du 26/11 ; décision JB du 26/11 sur les exclusions, pour que le reçu serve à un changement de doc seule.
